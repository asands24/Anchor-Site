# Integrations

Anchor integrates with your existing stack to unify support knowledge and workflows.

## Support Platforms
| Platform | Status | Capabilities |
| :--- | :--- | :--- |
| **Zendesk** | Available | Ticket deflection, Agent workspace app, Article ingestion |
| **Intercom** | Available | Inbox overlay, Article ingestion |
| **Freshdesk** | Beta | Ticket creation, Article ingestion |
| **Salesforce** | Enterprise | Case management, Knowledge sync |
| **HubSpot** | Roadmap | Service Hub integration |

## Knowledge Sources
- **Public URL**: Crawl any public sitemap or documentation site.
- **Notion**: Direct integration to read private wiki pages.
- **Google Drive**: Index PDFs and Docs (with permission controls).
- **Slack**: Index public channels for "tribal knowledge" (optional).

## API & Webhooks
For custom workflows, Anchor exposes a full REST API.
- **Query API**: Retrieve answers programmatically.
- **Ingest API**: Push content updates in real-time.
- **Webhooks**: Trigger actions on specific events (e.g., "Answer negative feedback").
