# Customization

Make Anchor look and feel like a native part of your product.

## Branding
- **Colors**: Match primary and secondary colors to your brand palette.
- **Logo**: Replace the Anchor avatar with your company logo.
- **Tone**: Adjust the AI persona (e.g., "Professional", "Friendly", "Concise", or "Pirate").

## Widget Behavior
- **Launcher**: Default circle icon or custom trigger element.
- **Greeting**: Set contextual greetings based on the page the user is viewing.
- **Direct Modes**:
  - **Search First**: Focus on finding articles.
  - **Chat First**: Focus on conversational resolution.

## Custom Actions
Define specific "Skills" for Anchor to execute.
- **Check Order Status**: Connect to your backend to pull real-time data.
- **Reset Password**: Trigger a password reset flow.
- **Schedule Call**: Integration with Calendly.

## CSS Overrides
For complete control, Enterprise plans allow raw CSS injection into the widget iframe for pixel-perfect matching.
